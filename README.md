# 写作风格路由

一个面向 MaiBot 的按需写作提示插件。它先通过 `chat.receive.before_process` 记录本轮用户原消息，再由 `maisaka.replyer.before_request` 按意图追加对应规则，只在本轮明确涉及创作或评文时生效。

## 特点

- 普通聊天、技术问答和群聊接话不注入写作规则。
- 不复制完整聊天上下文；明确关键词命中时不调用分类模型。
- 对疑似创作请求支持 `utils` 小模型语义补判；分类任务会在收消息时预热，并设有超时。
- 回复发送前支持 `utils` 活人感审核；只改明显 AI 腔，短回复、表情和代码块直接跳过。
- 支持按请求组合现代口语、搞笑网文、日系 ACG、反八股、人物生活化和评文规则。
- 已清理 MaiBot 不识别的变量、宏和幕后思维链写法。
- 中文说明是默认入口，English documentation 见 [README.en.md](README.en.md)。

## 自动触发

写作、续写、改写、重写、润色、扩写、仿写、小说、文风示例或示例文本等词会进入写作模式。

评文、点评、帮我看文、看看这段、分析文风或“这段有什么问题”等表达会进入评文模式。评文优先使用编辑视角，不会把正文改成角色扮演。

只有明确提到搞笑网文、梗小鬼、网感、沙雕、反差搞笑、轻小说、日系、ACG、二次元、漫画感或瀑布流时，才会追加相应风格。单独聊天提到“角色”“梗”或“现代”不会触发写作模式。

## 风格策略

写作请求默认组合现代口语、反八股和人物生活化规则；如果用户指定风格，再追加搞笑网文或日系 ACG 规则。评文请求组合评文、反八股和人物生活化规则。

规则强调对白自然、人物具体、节奏清楚和描写有依据，避免机械堆梗、模板化情绪标签、重复八股动作、职业腔和提示词泄漏。日系 ACG 的漫符、脑内吐槽和瀑布式排版只在用户明确要求时启用。

## 配置

配置文件为 [config.toml](config.toml)：

- `plugin.enabled`：总开关。
- `routing.max_prompt_characters`：单轮额外提示的最大字数，默认 `5200`。
- `styles.*`：分别控制各类风格是否参与路由。

插件不会改变原始 `extra_prompt`，而是将路由结果追加到现有提示后面，便于和角色记忆等插件联动。明确关键词走零等待快速通道；只有规则不确定的候选消息才会走 AI 语义补判，普通聊天不会调用分类模型。

回复后审核是独立的轻量流程：它会保留原意、事实、数字、链接、路径、命令和代码，只处理客服腔、模板化开场、机械总结和生硬过渡。审核超时、输出异常或改动过大时自动保留原回复。

## 安装

将整个 `writing_style_router` 目录放入 MaiBot 的 `plugins` 目录，确认 `config.toml` 中 `plugin.enabled = true`，然后重启 MaiBot。插件加载成功后，普通聊天无需额外操作。
